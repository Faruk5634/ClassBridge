# ClassBridge

ClassBridge is a planned school announcement and communication platform designed to connect educators and students seamlessly. This project is currently in the initial setup phase.

## Project Structure

- `backend/`: A Spring Boot backend application built with Java 17 and Maven. It is set up with dependencies for Spring Web, Spring Security, Spring Data JPA, Validation, and PostgreSQL. 
- `frontend/`: A React frontend application built with TypeScript, initialized via Vite, and configured with Tailwind CSS.
- `docs/`: Project documentation.
